# 13 → 14

Version 14 replaces the Actor-plus-root-component model with one `SceneNode`
tree. Migrate structure and lifecycle first, then helpers and any serializer
call sites. Existing serialized scenes and prefabs from supported versioned
formats migrate in memory when loaded; project TypeScript still needs the
changes below.

Apply steps in order. Open a detail file only when that area appears in the
project (search hits or compile errors).

`Actor` and `ActorOptions` survive as deprecated compatibility shims, but the
project lint preset sets `@typescript-eslint/no-deprecated` to **error** — so
`pnpm lint` fails on every remaining reference to them, and to `getActor()`,
`getComponent(s)`, and the other deprecated shims named below. Treat the
deprecations as migration work you must finish, not warnings you can defer. Run
`pnpm lint` early: it locates every one of those call sites for you.

If a class genuinely cannot move yet, scope the escape hatch to that line rather
than disabling the rule project-wide:

```ts
// eslint-disable-next-line @typescript-eslint/no-deprecated
class LegacyCrate extends ENGINE.Actor {}
```

## Migration checklist

1. **Roots** — Prefer `SceneNode`/`PrimitiveNode` with `isRoot: true`. Single
   former `rootComponent` → promote that node (no wrapper); compound
   `rootComponent` + `sceneComponents` → placeable + `children` and lift
   physics to the root. `Actor` remains a deprecated compatibility root;
   its `rootComponent` getter returns **`this`** — never forward an override
   like `setHiddenInGame` through `this.rootComponent.…` (infinite
   recursion). Remove Actor `setRootComponent` / `collapseRootComponent`
   (`Prefab` uses `rootNode`). **Pawn, Controller, PlayerStart, Projectile,
   InfoNode/GameMode, VRNode, ModelMeshActor** no longer extend `Actor` —
   audit `instanceof Actor`, Actor-typed APIs, and use `getNodes*`; the
   `getActors*` lookups are gone. Plain Pawn
   no longer snap-replicates transforms (prefer `MovementPawn` /
   `PawnNetTransform`). Custom non-Actor/non-Pawn roots need an explicit
   `ReplicationGroup` (`replicated = true` alone is not enough; Actor and
   Pawn auto-ensure).
2. **Names** — Rename scene `*Component` types to `*Node` (aliases/redirects
   keep assets loading). Prefer `InfoNode` / `VRNode`. Fix deep imports under
   deleted `components/**`. Renamed `GAME.*` classes need
   `ClassRegistry.addClassesToRedirect`.
3. **Lifecycle** — Replace `doBeginPlay`/`doEndPlay` with
   `beginPlay(): boolean` / `endPlay(): boolean` (call `super` first).
4. **World** — Treat World as the scene graph (`world.add` /
   `getRootNodes` — hard rename from `getWorldRootNodes` /
   `getPlayerControllerAt` / `getNode`). Use `getRenderScene()` for
   background/environment. Rename Level/GameLoop preserve APIs (`nodes`,
   `preserveRoots`, `*Roots*` hooks).
5. **Queries / tags** — `getRoot`/`getNode(s)` instead of
   `getActor`/`getComponent(s)`; Actor tags → `SceneNode` tags.
6. **Gameplay** — Collision delegates on `PrimitiveNode` (3-arg);
   `hitNode` / `thisNode`/`otherNode`; CharacterPawn
   `createCollision` / `createMovementNode` / `setup*Node`;
   MoverCharacterPawn `createMoverNode`; other removed Actor helpers.
7. **Serialization** — Rename removed serializer/prefab helpers; open scenes
   and prefabs then **save** to persist V3 (`children` dump key).
8. **Multiplayer (if used)** — `GroupUpdateType`/`groups`,
   `sendLoadLevel`/`sendLevelLoaded`, `NodePath` net sub-ids,
   `netType: 'actorRef'` → `'nodeRef'` (see hierarchy).
9. **Rendering (only if `material.mrtNode` is set)** — remove the assignment; AO
   validity now comes from `material.transparent` (see rendering).

Treat `rootComponent` / `setRootComponent` contextually (obsolete on Actor —
getter returns `this`; `Prefab` uses `rootNode`). Any
`rootComponent.setHiddenInGame` / `rootComponent.visible` inside an Actor
subclass override of the same API is a recursion bug — rewrite to `super` /
`this`. Treat `hitActor` contextually (physics → `hitRoot`;
`InstantHitWeaponNode` payloads still use `hitActor`). Treat `handleDeath`
contextually (Actor helper gone; `CharacterStatsNode.handleDeath` remains).

Then:

1. Run `pnpm build`, then `pnpm lint`.
2. Open every scene and prefab; confirm roots, children, transforms, overrides.
3. Exercise play/stop twice; collision/overlap; multiplayer if applicable.
4. Save authored assets only after inspection, then rerun build and lint.

When a step is ambiguous, confirm the signature in `.engine/` — each detail
file lists the most relevant sources.
