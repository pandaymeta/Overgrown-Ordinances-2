# Hotkeys

| Hotkey | Action |
| --- | --- |
| `Ctrl/Cmd+S` | Save Scene |
| `Ctrl/Cmd+B` | Build Project |
| `Ctrl/Cmd+Z` | Undo |
| `Ctrl/Cmd+Y` | Redo |
| `Ctrl/Cmd+D` | Duplicate selection |
| `Ctrl/Cmd+C` / `V` | Copy / Paste (Outliner focused — actors) |
| `Ctrl/Cmd+P` | Exit Play Mode (while playing) |
| `Ctrl/Cmd+E` | Show in Explorer |
| `Ctrl/Cmd+R` | Reload |
| `Ctrl/Cmd+Q` | Quit |
| Del / Backspace | Delete selection (folders: Del = delete content; Shift+Del = keep content) |
| Escape | Exit play; close prefab; restore previous selection; clear selection / Select tool |
| Q / W / E / R | Select / Move / Rotate / Scale |
| X | Toggle World / Local |
| H | Toggle editor visibility (editor-only) |
| L | Toggle editor lock (editor-only) |
| F | Focus / frame selection |
| Shift+F | Scroll Outliner to selection (Outliner focused) |
| F2 | Rename |
| End | Drop selection to surface |
| 1 | Toggle AI Assistant |
| Space | New Agent Chat overlay |
| F5 | Play Game Default Scene (or exit if playing) |
| F6 | Play Current Scene |
| F11 | Toggle full screen |
| F12 | Toggle Dev Console |

Property clipboard (Inspector): **Copy Value** Shift+RMB · **Paste Value** Shift+LMB — not global hotkeys.
